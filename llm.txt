# Ticket Flow

> Free public guide for a thin IDE agent checklist: ticket ID → branch → implement → tests → Confirm before commit → Confirm before PR → optional chat notify. Cursor skill + rules + script wrappers. Does not fetch tickets, create PRs, or post to chat from this website.

Canonical site: https://smg99.github.io/ticket-flow/
GitHub: https://github.com/smg99/ticket-flow
Companion (AI-assisted SDLC prompts): https://smg99.github.io/engineering-ai-playbook/

## Who it is for

- Engineers using Cursor (or similar agents) on real tickets
- Leads who want Confirm gates before commit/PR without building a platform
- Teams already using the AI-Assisted SDLC Playbook for pre-ticket stages

## High-intent topics this site answers

- What is Ticket Flow?

## Flow steps (contract)

Queue → Fetch issue → Branch → Implement & test → Confirm before commit → Stage & commit → Confirm before PR → Push & open PR → Ask before chat → Close out / consumer bump
